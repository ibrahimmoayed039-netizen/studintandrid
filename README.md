# حضور الطلبة (NFC) — تطبيق أندرويد

تطبيق أندرويد بلغة **Kotlin** و **Jetpack Compose** لتسجيل حضور الطلبة بتمرير بطاقة NFC على ظهر الهاتف.
البيانات محفوظة **محلياً** في قاعدة **Room (SQLite)** وتبقى بعد إغلاق التطبيق.

## المزايا
- قراءة بطاقات NFC مباشرة بالهاتف (Reader Mode) — لا يحتاج قارئاً خارجياً.
- دعم قارئ NFC/RFID خارجي (USB OTG أو بلوتوث) يعمل كلوحة مفاتيح: يلتقط الرقم تلقائياً دون الحاجة لحقل نصي.
- الطلاب: إضافة/تعديل/حذف، صورة، وربط البطاقة بمسحها مباشرة داخل نموذج الطالب.
- الجدول الأسبوعي مع وقت الانتهاء، وبدء/إنهاء تلقائي اختياري، ولافتات الاستراحة بين الحصص.
- شاشة المسح: نتيجة ملوّنة (حاضر/متأخر/مكرر/غير مسجّل) مع اهتزاز وصوت.
- حضور يدوي لمن نسي بطاقته، واختيار طالب عشوائي من الحاضرين.
- وضع ملء الشاشة للمسح (Kiosk) مع إبقاء الشاشة مضاءة أثناء المحاضرة.
- السجل حسب التاريخ، قائمة الغائبين لكل محاضرة، وتصدير CSV (يفتح في Excel بالعربية).
- **المستخدمون والصلاحيات:** تسجيل دخول بكلمة مرور مشفّرة (PBKDF2). المدير يرى كل شيء ويدير الطلاب والمستخدمين والإعدادات، والمدرّس يرى جدوله ومحاضراته فقط.
- **التقارير:** تقرير المحاضرة والغائبين (مع تسجيل حضور من القائمة)، وتقرير شهري لكل طالب بنسبة الحضور، وتصدير CSV لكليهما.
- **نسخ احتياطي:** تصدير واستيراد نسخة كاملة بصيغة JSON (الطلاب مع صورهم والجدول والحضور والمستخدمون والإعدادات).
- تصميم مجسّم داكن (بطاقات زجاجية، أزرار بارزة تنضغط، واجهة RTL).

## بناء ملف APK

### الطريقة 1: Android Studio
1. ثبّت **Android Studio** (Koala أو أحدث) ثم `File → Open` واختر مجلد المشروع.
2. انتظر انتهاء Gradle Sync (يحتاج إنترنت أول مرة).
3. لتجربة سريعة: وصّل هاتفك (تفعيل USB debugging) ثم Run ▶.
4. لإخراج APK: `Build → Build Bundle(s) / APK(s) → Build APK(s)`
   الناتج: `app/build/outputs/apk/debug/app-debug.apk` — انقله للهاتف وثبّته.

### الطريقة 2: سطر الأوامر
```bash
./gradlew assembleDebug
```
(يتطلب JDK 17 وAndroid SDK 34).

### الطريقة 3: GitHub Actions (بدون تثبيت شيء)
ارفع المشروع إلى مستودع GitHub؛ سيعمل `.github/workflows/build-apk.yml` تلقائياً،
ثم حمّل الـ APK من تبويب **Actions → آخر تشغيل → Artifacts → attendance-apk**.

### نسخة الإصدار (Release) الموقّعة
ملف `app-debug.apk` صالح للتثبيت والاستخدام. للنشر على متجر Play:
`Build → Generate Signed Bundle / APK` وأنشئ مفتاح توقيع (احتفظ به ولا ترفعه للمستودع).

## ملاحظات مهمة
- **أول دخول:** المستخدم `admin` وكلمة المرور `1234` — غيّرها فوراً من تبويب «المستخدمون ← كلمة المرور».
- ملف النسخة الاحتياطية يحتوي بيانات الطلاب وتجزئة كلمات المرور، فاحفظه في مكان آمن. الاستيراد **يستبدل** كل البيانات الحالية.
- النسخة الاحتياطية خاصة بتطبيق الأندرويد، ولا تُستورد فيها ملفات نسخة الحاسوب.
- الترحيل من الإصدار الأول محفوظ: الجدول والمحاضرات القديمة تُنسب تلقائياً للمدير.
- **الحد الأدنى:** أندرويد 8.0 (API 26). الهاتف يجب أن يدعم NFC ومفعّلاً.
- **رقم البطاقة:** يُقرأ كـ UID بصيغة HEX كبيرة (مثل `04A1B2C3`). سجّل البطاقات من نموذج الطالب بزر «مسح البطاقة».
  الأرقام المخزّنة في تطبيق سطح المكتب (إن كانت من قارئ USB) قد تكون بصيغة مختلفة، لذلك أعد ربط البطاقات من هذا التطبيق.
- التشغيل التلقائي للجدول يعمل أثناء فتح التطبيق فقط.
- النسخ الاحتياطي عبر تخزين Android التلقائي مفعّل (`allowBackup`)، ولا يوجد تصدير/استيراد يدوي بعد.

## هيكل الشيفرة
| الملف | الوظيفة |
|---|---|
| `data/Data.kt` | كيانات Room (مستخدمون، طلاب، جدول، جلسات، حضور) وDAOs والترحيل |
| `data/Passwords.kt` | تجزئة كلمات المرور |
| `data/Backup.kt` | تصدير/استيراد JSON |
| `data/SettingsStore.kt` | الإعدادات المحفوظة |
| `MainViewModel.kt` | منطق المسح والجلسات والجدول التلقائي |
| `MainActivity.kt` | قراءة NFC والتبويبات |
| `ui/*` | الشاشات (مسح، طلاب، جدول، سجل، تقارير، مستخدمون، إعدادات، دخول) والمكوّنات والثيم |
